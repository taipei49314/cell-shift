# Depth watch (unattended)

L3 (剖切、培養皿、著色秀) is **closed**. Do not open it.

This file is the contract for unmanned deepening. An agent that cannot point at a line here must stop.

## Goal

Make CELL//SHIFT a **personal research instrument** that can close a question without a person at the keyboard: run a protocol, issue a receipt, sweep a parameter, score a pre-registered hypothesis. Still not a biological model. [CLAIMS.md](CLAIMS.md) Not-claimed rows are frozen.

## Allowed work (in order)

1. **L2 receipts** — issue / parse / replay / verify; UI Export + Load; `npm test` round-trip.
2. **Headless chamber** — `npm run chamber -- run <protocol> <hours>` writes a receipt JSON.
3. **Campaigns** — one-factor sweeps (adhesion, oxygen, SHIFT cycle_rate) → `artifacts/campaigns/*.json`.
4. **Hypothesis ledger** — pre-register, run, write PASS/FAIL/UNKNOWN. Never backfill.
5. **Multi-seed robustness** — same protocol, seeds `{4821, 7, 21, 99, 2026}`. Report how many hold. Do not silently drop failing seeds.
6. **More locked questions in the same three classes only** (structure / selection / shape). New `npm test` rows required.

## Forbidden

## Stop conditions (unattended must halt)

- Temptation to "just polish the 3D"
- Next change would expand the question classes

- Receipts round-trip under test
